# HUNT Skill — Visual Order Guard

## Purpose
Protect the homepage from returning to scroll chaos as new features are added.

## Inspect on every homepage change
- direct child order under #main-content;
- containment of legacy sections inside their assigned floor;
- duplicate IDs;
- horizontal overflow;
- category menu contract and entry triggers;
- major department card-count balance;
- abnormally tall floors;
- mobile two-column product rhythm;
- ad content escaping the Advertising floor;
- HUNT NOW escaping the AI floor;
- Night Edit / Mission Builder escaping the Penthouse.

## Failure behavior
Set body[data-hunt-visual-order="review"] when any structural check fails.
Dispatch hunt:visual-order-audit with a machine-readable report.
Never silently repair commercial truth or hide an error by inventing content.

## Human visual QA
The runtime guard is necessary but not sufficient.
Before Production, visually inspect:
- desktop wide;
- desktop 1280;
- tablet;
- mobile 390;
- menu open and closed;
- first screen, mid-building, Market Hall, Ads, AI, Media, Penthouse.
