# HUNT F35 — Product Finding & Factual Compare

## Objective
Reduce scanning friction on category and search result pages while preserving product truth.

## Implemented

### Applied Filters Overview
Category pages now show an explicit applied-filter overview for active section and price constraints.
Each filter can be removed individually, and all filters can be cleared at once.
The overview disappears when no filters are active.

### Result Context
Subcategory navigation shows live counts derived from the currently loaded, quality-approved catalog rows.
The main result count continues to distinguish total matches from currently displayed products.

### Category-Specific Product Facts
Cards show up to two available facts selected by product world:
- Tech / Office: model, brand, options, type.
- Fashion: brand, options, type.
- Beauty: brand, type, origin.
- Home: type, options, origin.
- Other categories: available brand/options/type.
Unknown facts remain absent instead of being inferred.

### Factual Compare
Category and Search results support a persistent Compare facts control.
- Maximum 3 products.
- Persistent tray shows what is selected.
- Comparison table contains only known facts.
- No winner, score, ranking, or purchase recommendation.
- Unknown remains Unknown.
- Restricted or unsafe product categories are excluded from the comparison runtime.

### Search Price Truth
Search results no longer present arbitrary retail_price_amount values as a retail price.
A price is shown as verified only when retail_price_verified=true and Profit Gate is PASS.
Otherwise Search says that price is checked on the product page.

### Interaction Feedback
Applying filters sets aria-busy on the grid before filtering and clears it after the render.
This gives the browser an opportunity to paint feedback before larger list work.

### Runtime Resilience
Compare has a one-time self-healing loader in Category and Search if an initial script load is missed.
Compare runtime is cache-bumped and included in the PWA shell.

## QA Evidence
- Category Tech: 198 loaded matches, 48 visible cards.
- 48 category-specific fact groups rendered.
- Subcategory counts verified in browser.
- Applied price filters appear as removable chips.
- Clear all restores the product list.
- Two products can be selected into a persistent tray.
- Factual comparison table verified with 2 products + fact column.
- Mobile 390px: no horizontal overflow; compare tray remains above mobile navigation.
- Search "phone case": 36 visible results, 36 fact groups, 36 compare controls.
- Search does not expose unverified "From" prices.

## Research basis
The implementation follows current ecommerce UX findings around:
- applied filter overviews;
- category-specific list item information;
- comparison for spec-driven products;
- quick visual feedback and interaction responsiveness.

## Guardrails
No fake scarcity, urgency, popularity, rating, stock, delivery, or discount claims.
No ranking or winner is generated by Compare.
Missing information stays unknown.
