# BOOM Global Growth Plan — $10K/day Target

## Principle
$10,000 net profit per day is a target, not a forecast or promise. BOOM must first prove unit economics using real supplier costs, shipping, returns, fees, taxes and verified order data.

## Three parallel lanes

### Lane A — Catalog Scale
Goal: 20K–30K+ unique safe products without slowing HUNT.
Order of work:
1. Keep CJ + Gooten + Printful stable.
2. Connect one free/free-tier API source first: Prodigi, Gelato or Printify.
3. Add a second source only after catalog quality and performance pass.
4. Prioritize weak categories: swimwear, phone accessories, gaming, socks.
5. Keep category shards and progressive rendering.

Success:
- unique safe catalog count rises materially
- no category shrink after live refresh
- mobile first render stays fast
- zero unsafe/restricted catalog contamination

### Lane B — Premium / Brands / Fragrance
Goal: add authenticated global brands and higher-margin inventory.
Priority sequence:
1. BrandsGateway — luxury fashion / suits / women / men / shoes / bags / accessories.
2. Mytheresa — luxury affiliate feed.
3. Sephora — beauty/fragrance affiliate lane.
4. FragranceX — authentic fragrance wholesale/reseller route.
5. Other approved luxury/beauty partners after terms review.

Rules:
- never label a brand connected before approval
- authentic fragrance only through authorized/verified sources
- exact product and price/feed relation required
- fulfillment/returns truth documented before onsite paid checkout

### Lane C — Free Growth First
Goal: prove demand before paid media.
1. Search Console + sitemap indexing
2. technical/product SEO
3. product-native organic content
4. sharing, saves and referral loops
5. country localization
6. Google free-listing readiness where eligible
7. onsite A/B tests in BOOM Marketing Lab

Paid media starts only after:
- conversion ladder is verified
- fulfillment + returns are documented
- real retail pricing is available
- landing pages are fast
- attribution is ready
- owner approves the exact campaign and budget

## $10K/day target unit-economics ladder

Illustrative contribution scenarios:
- $20 net contribution/order -> 500 orders/day
- $40 net contribution/order -> 250 orders/day
- $60 net contribution/order -> about 167 orders/day
- $100 net contribution/order -> 100 orders/day

At 250 orders/day, illustrative qualified-traffic needs:
- 1% conversion -> about 25,000 visits/day
- 2% conversion -> about 12,500 visits/day
- 3% conversion -> about 8,333 visits/day
- 4% conversion -> about 6,250 visits/day

These are planning examples only. BOOM replaces them with real numbers as soon as verified order economics exist.

## BOOM Chess Loop
Every day:
SCAN -> VERIFY -> SCORE -> PICK MOVE -> TEST -> MEASURE -> KILL / KEEP -> LEARN.

Every move must answer:
- what user problem does this solve?
- what signal proves it?
- what is the expected upside?
- what could go wrong?
- what is the control?
- what is the kill condition?
- what is the next move if it wins?

## Priority KPIs
Before real checkout:
- organic impressions
- indexed URLs
- product-open rate
- save/like rate
- cart rate
- related-product open rate
- repeat visit rate
- recommendation diversity

After verified purchases:
- conversion rate
- AOV
- contribution margin/order
- refund/return rate
- repeat purchase rate
- CAC
- ROAS
- net contribution/day

## Hard rule
BOOM never optimizes for vanity metrics when they conflict with trust, real margin or repeat behavior.
