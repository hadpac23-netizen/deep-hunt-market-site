# HUNT 2037 — Official Execution Plan

Status: Active execution plan
Branch: feature/boom-brand-factory-v1
Date: 2026-09-18

## 1. Objective

Turn the existing HUNT storefront and BOOM Studio into HUNT 2037 without destroying approved working systems.

Execution rule:
**Brain first → one working vertical slice → dynamic experience → styling/mirror → growth → production gates.**

No giant rewrite.
No fake completion.
No production activation without evidence and owner approval where required.

## 2. Current baseline

Already available or partially available:
- BOOM Executive Brain and manager registry.
- HUNT 2037 Operating Brain.
- Decision Brain pilot with tests.
- Country/localization and shipping foundations.
- Product Truth / inventory / sale-readiness foundations.
- Device-level personalization signals.
- Complete-the-Look / Deal Builder foundation.
- Brand Factory / Media Vault / Visual QA foundations.
- HUNT 2037 Blueprint, Build Prompt and Phase 0 Audit.

This means execution starts from an existing architecture, not from zero.
## 3. Preservation contract

Preserve existing approved:
- managers,
- owner gates,
- checkout/payment protections,
- security,
- Product Truth,
- supplier rules,
- Brand Factory safety,
- release controls,
- storefront fallback behavior.

Modify existing behavior only when:
- required for integration,
- proven defective,
- conflicting with current truth,
- or explicitly requested by owner.

Every material change needs:
- reason,
- files/components affected,
- tests,
- rollback/fallback.

## 5. Phase 1 — Brain Foundation Integration

Goal:
Make BOOM Studio understand and route the entire HUNT 2037 system correctly.

Build:
- manager routing map,
- capability states,
- normalized Decision Brain contract,
- event schema,
- Taste DNA schema,
- Memory contract,
- experiment contract,
- knowledge freshness rules,
- decision reason codes,
- feature flags.

Deliverable:
BOOM can answer:
- what is live,
- what is partial,
- what is planned,
- what is blocked,
- which manager owns it,
- which manager may veto it,
- whether owner approval is required.

Exit gate:
- brain regression suite PASS,
- no existing manager lost,
- no owner gate weakened,
- all new capabilities have truth states.

## 6. Phase 2 — Country + Product Truth Normalization

Goal:
Make every recommendation market-aware before it becomes visual.

Normalize:
- country
- warehouse
- exact SKU/variant
- stock
- shipping
- ETA
- landed cost
- restrictions
- return feasibility
- margin
- freshness timestamp

Deliverable:
One country-aware candidate object consumed by Decision Brain.

Exit gate:
A candidate that is unavailable, stale, blocked, or unprofitable cannot silently rank as normal.

## 9. Phase 5 — Dynamic Worlds + HUNT Visual Identity

Create the visual system for HUNT 2037.

### Dynamic HUNT wordmark
The HUNT identity may:
- shift color,
- move,
- bounce/subtly react,
- transition by world,
- react to session context.

Rules:
- motion stays tasteful,
- no constant distracting animation,
- respect reduced-motion,
- never hurt readability.

### Night City Layer
Use a curated licensed/original high-quality night-city visual library.

Candidate cities may include:
- Dubai
- London
- Tokyo
- Seoul
- Singapore
- Hong Kong
- Shanghai
- Shenzhen
- New York
- Los Angeles
- Chicago
- Paris
- Milan
- Berlin
- Copenhagen
- Barcelona
- Mumbai
- Cape Town
- additional global cities as the library grows

Cities may appear as:
- atmospheric hero backdrops,
- parallax layers,
- slow transitions,
- world separators,
- regional discovery moments.

Do not use random city photography as decoration.
The city layer must remain secondary to products and performance.

Exit gate:
HUNT feels alive without becoming visually noisy or slow.

## 18. Build philosophy

Do not wait for the complete vision before proving value.

Each phase must produce:
1. working code,
2. tests,
3. evidence,
4. a reversible change,
5. a clear next dependency.

The final HUNT should feel radically different because the system is intelligent underneath — not because animation was added on top.
