# HUNT GLOBAL DISTRIBUTION OS — Skill Pack V1

## Governance
Before creating any skill:
AUDIT → REUSE → EXTEND → CREATE ONLY IF MISSING

Every skill must expose: mission, required inputs, truth requirements, output schema, confidence, reason codes, blockers, fallback, success metrics and Owner Gate requirement.

## Canonical Skills
1. hunt-product-passport — one verified canonical commerce record. UNKNOWN never becomes invented truth.
2. hunt-feed-syndication — one canonical Product Passport into channel adapters for Google, Microsoft/Bing, Pinterest, OpenAI/AI-ready feeds and future approved channels.
3. hunt-distribution-score — per-channel suitability from truth quality, media, demand, economics, shipping, category fit and historical performance.
4. hunt-distribution-router — PRODUCT → MARKET → CHANNEL → FORMAT → PRIORITY. Do not send every product everywhere.
5. hunt-ai-visibility-geo — measure HUNT visibility inside AI-powered discovery.
6. hunt-publisher-network — publisher identity, feeds, API, widgets, collections, tracked links and commission attribution.
7. hunt-price-intelligence — verified price history, Price Watch, Price Drop, Deal Quality and Lowest Verified Price. No fabricated historical price.
8. hunt-creator-discovery — lawful/public/authorized discovery of relevant adult creators.
9. hunt-creator-match — creator fit × product fit × market × stock × shipping × contribution.
10. hunt-affiliate-attribution — CLICK ID → SESSION → ORDER → FULFILLMENT → RETURN WINDOW → COMMISSION.
11. hunt-ugc-governance — consent, rights, product match, moderation and Verified Purchase truth.
12. hunt-owned-audience — wishlist, saves, price alerts, stock alerts, email, push and opted-in messaging with consent/opt-out.
13. hunt-content-factory — TRUTH → HOOK → SCRIPT → EXACT MEDIA → CLAIM CHECK → QA → CHANNEL FORMAT.
14. hunt-community-distribution — HELP → DATA → ANSWER → OPTIONAL HUNT RELEVANCE. Never mass promotion or spam.
15. hunt-referral-engine — rewards only after qualified transaction state with abuse controls.
16. hunt-localization — language, currency, shipping, season, demand, local platform and cultural context. Translation alone is insufficient.
17. hunt-profit-attribution — Revenue minus landed cost, shipping, payment fees, affiliate/creator cost, marketing cost and refund/return cost = Verified Net Contribution.
18. hunt-media-intelligence — publishable commerce intelligence only with sufficient evidence.
19. hunt-shareable-tools — useful, shareable and attributable tools such as Gift Finder, Outfit Builder, Setup Builder, Compare, Find Under Budget, Deal Checker and HUNT THIS DEAL.
20. hunt-distribution-evals — continuous evaluation of feeds, stock, country, margin, price-drop truth, media match, creator match, attribution, spam, localization, duplication and model overconfidence.

## Final Principle
HUNT does not buy attention first. HUNT earns, distributes, measures and compounds attention.

Every product must answer:
1. Where can this product be discovered for free or performance-based cost?
2. Where does it generate verified profit?
3. How do we increase distribution there without damaging trust or margin?
