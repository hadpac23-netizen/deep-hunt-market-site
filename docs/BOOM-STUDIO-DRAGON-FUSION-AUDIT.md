# BOOM Studio → DRAGON CORE Fusion Audit

Status: BRANCH-ONLY / SHADOW / NO PRODUCTION EFFECT  
Canonical registry: `boom-dragon-fusion-registry.json`

## Decision

DRAGON CORE becomes the primary visual command center, but it does **not** replace or delete the older BOOM Studio capabilities.

The consolidation rule is:

`OWNER → BOOM Orchestrator → Domain Brain → Agent/Worker → Skill → Tool → Verifier → Policy/Owner Gate → Evidence → Learning`

Legacy Studio systems are extracted as capabilities and mapped into one canonical owner. Their old runtime ownership must not be duplicated.

## Anti-duplication rules

Do not create:
- a second Orchestrator,
- a second runtime/Supabase owner,
- a second Product Truth,
- a second Checkout/Payment owner,

- a second Memory layer,
- a second Learning system.

`DISCOVER → CLASSIFY → MAP OWNER → EXTRACT CAPABILITY → REWIRE → TEST → OWNER REVIEW`
