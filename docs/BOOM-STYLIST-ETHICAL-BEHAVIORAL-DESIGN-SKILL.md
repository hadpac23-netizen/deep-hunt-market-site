# BOOM Stylist + Ethical Behavioral Design Skill

## Purpose
Create strong attraction without manipulation.

## Core disciplines
### HCI engineering
Minimize cognitive load, preserve spatial stability, make controls predictable, and reveal complexity progressively.

### Visual perception
Use hierarchy, contrast, grouping, rhythm and focal points so the eye knows where to look without forcing it.

### Cognitive psychology
Use recognition over recall, chunking, familiarity, clear comparisons and meaningful novelty.

### Behavioral economics
Use choice architecture to simplify decisions, not to trap users. Default to transparency and reversible exploration.

### Trust engineering
Keep verification language visible where it matters. Never hide uncertainty. Unknown remains unknown.

### Retail merchandising
Build coherent edits, complementary sets, category worlds and editorial stories using real catalog data.

### Motion engineering
Motion communicates hierarchy and state. It is not decoration for its own sake.
Strong motion: brand signature.
Medium motion: scene/discovery transition.
Subtle motion: cards and status.
Never animate critical prices or checkout controls to create pressure.

## Attraction patterns allowed
- editorial curation;
- personalized relevance;
- visual storytelling;
- tasteful surprise;
- complementary-product composition;
- clear comparison;
- rich imagery;
- micro-interaction delight;
- progress through discovery;
- elegant brand memory.

## Patterns forbidden
- fake scarcity;
- countdown pressure;
- confirm-shaming;
- hidden fees;
- disguised ads;
- fake social proof;
- compulsive reward loops;
- manipulative loss framing;
- targeting vulnerability or sensitive identity.

## Dynamic detail system
BOOM can rotate one small explanatory/mood line every 12–16 seconds when visible.
It pauses when the document is hidden.
It never rotates legal, price, stock, shipping or checkout truth.

## AI contract
AI returns only enumerated presentation decisions and short safe copy.
Client re-validates every AI response.
No raw PII or payment information enters the AI prompt.

## F35 Kill Test
Reject the build if:
- AI failure breaks HUNT;
- AI can alter commerce truth;
- a recommendation is based on a sensitive trait;
- motion moves a target while the user acts;
- copy creates fear or urgency;
- section dynamics cause horizontal overflow;
- a user cannot stop/ignore automation;
- reduced motion is not respected.
