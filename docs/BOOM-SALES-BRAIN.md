# BOOM Sales Brain — Deal Composer

Goal: increase conversion and basket value by solving a shopper need, not by using pressure.

## Deal hierarchy
1. Verified supplier/marketplace promotion — show first.
2. Smart Set — complementary products with no savings claim unless verified.
3. Price Edit — real current products under a truthful price threshold.
4. Personalized Edit — based on current shopping behavior.
5. Sponsored placement — always labeled.

## Core deal recipes
- COMPLETE THE LOOK: bag + jewelry + scarf/hair accessory/shoes.
- PHONE PROTECTION SET: case + screen protector + camera protection or strap.
- PHONE STYLE DUO: two compatible cases/colors when a supplier supports quantity pricing.
- STARTER KIT: hero product + needed accessory, e.g. espresso machine + grinder/tool.
- GIFT SET: 2–4 complementary items that feel complete as a present.
- FREE-SHIPPING THRESHOLD: only when real landed economics support it.
- BUY MORE SAVE MORE: only with supplier-funded or margin-verified tier pricing.
- LAUNCH DROP: new curated SKUs; urgency only if the supplier gives a real end date or stock limit.
## Deal naming rule
Name the outcome, not the mechanism.
Prefer:
- Complete the Look
- Ready-to-Go Phone Setup
- Everyday Jewelry Edit
- Weekend Bag Edit
- Coffee Starter Setup
- Gift-Ready Set

Avoid:
- MEGA SALE
- LAST CHANCE
- ONLY 2 LEFT
- 70% OFF
unless each claim is currently verified.

## Persuasion formula
1. RELEVANCE — show why this fits what the shopper is doing now.
2. CLARITY — one benefit sentence, not a paragraph of hype.
3. PROOF — real price, compatibility, material, reviews/QC, shipping.
4. CHOICE — let the shopper buy individually or as a verified bundle.
5. NEXT STEP — one obvious CTA.
## Supplier negotiation for deals
Ask the supplier to choose one commercially workable structure:
- fixed package price for selected SKUs
- supplier-funded coupon
- volume rebate
- free/reduced shipping threshold
- free gift with a defined SKU
- limited launch price with exact dates
- mixed-SKU quantity discount

Require in writing:
- eligible SKUs
- countries
- start/end dates
- stock/quantity limits
- who funds the discount
- stacking rules
- shipping treatment
- returns treatment

## BOOM sales guardrails
Never fabricate scarcity, reviews, discounts, MSRP or savings.
Never rank solely by commission.
Never hide mandatory cost until checkout.
Never create a bundle that forces irrelevant products.
Optimize conversion + contribution margin + returns together.

Rule: the smartest sale is the one the shopper understands and still likes after delivery.
