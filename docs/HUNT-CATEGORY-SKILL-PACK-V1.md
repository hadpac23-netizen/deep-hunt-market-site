# HUNT Category Architecture — Skill Pack V1

## 1. HUNT Taxonomy Architect
Owns canonical Department → Family → Leaf identity.
Rejects supplier-first classification and overlapping canonical routes.

## 2. HUNT Legacy Migration Mapper
Maps every existing shelf to KEEP / REMAP / MERGE / CROSS_SURFACE_FILTER / REVIEW / BLOCK.
Never deletes source evidence.

## 3. HUNT Navigation IA
Owns the 17-department rail, family button hierarchy, View All behavior and desktop mega-menu information architecture.

## 4. HUNT Mobile Commerce Navigation
Owns sticky horizontal department chips, selected scope, drill-down, touch targets and back-navigation context.

## 5. BOOM Stylist Merchandising
Owns ranking, audience, occasion, trend, season, giftability and personalization.
Cannot change canonical taxonomy.

## 6. HUNT Product-Finding UX
Owns search/category suggestions, breadcrumbs, scope preservation, filters and related category links.

## 7. HUNT Catalog Density Gate
Enforces public button thresholds:
HEALTHY >=24
THIN 12–23
VERY_THIN 1–11
MISSING 0
Prevents empty/dead-end public shelves.

## 8. HUNT Commerce SEO Architecture
Owns canonical URLs, internal links, H1/breadcrumb naming and prevention of duplicate indexable taxonomy routes.

## 9. HUNT Accessibility QA
Checks keyboard/focus behavior, screen-reader labels, selected states, contrast, touch targets and non-color scope indicators.

## 10. HUNT Taxonomy Red Team
Actively attacks classification with known failure patterns:
giftable jewelry,
animal-print human clothing,
shoe storage,
cosmetic storage,
phone ring holders,
smart-watch vs watch accessories,
car mirrors,
unisex apparel,
baby/adult conflicts,
kids home goods,
supplier category corruption.

## 11. HUNT Regression & Incident Team
Locks corrected cases into regression tests.
Any new catalog fill must pass the same taxonomy contract before it can enter a shelf.

## 12. Profit & Availability Gate
Runs after taxonomy.
Owns supplier cost, Market5, destination shipping, contribution and Sell Ready gating.
Never influences classification simply to make a shelf look full.
