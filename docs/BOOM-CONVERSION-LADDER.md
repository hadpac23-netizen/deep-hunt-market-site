# BOOM Conversion Ladder

BOOM must optimize the nearest honest measurable step, not pretend every click is a sale.

1. Recommendation impression
2. Product / related-product open
3. Like or Save
4. Add to cart
5. Checkout preview
6. Verified real purchase
7. Repeat visit / repeat verified purchase

## Rules
- Micro-conversions are not purchases.
- A product impression is not demand.
- A click is not revenue.
- Purchase is emitted only for a confirmed real order.
- Paid-media optimization remains locked until tracking + fulfillment + returns + pricing truth + owner approval pass.
- Compare experiments against a control where practical.
- Protect diversity, site performance, trust and return/refund guardrails.
