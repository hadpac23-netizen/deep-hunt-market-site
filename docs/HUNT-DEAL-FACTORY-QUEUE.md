# HUNT Deal Factory Queue

## Rules
- SMART SET = complementary products; no savings claim unless verified.
- COMPATIBILITY EDIT = same phone model only; no bundle claim.
- SUPPLIER BUNDLE = same supplier, exact SKUs, written package price and terms.
- VERIFIED DEAL = active evidence, source URL, dates and price proof.

## Requested terms
For every supplier bundle:
- exact SKUs
- individual wholesale prices
- package/bundle price
- MOQ
- sample price
- photos/video + media-use permission
- QC/material evidence
- fulfillment countries
- launch price validity
- returns/warranty treatment
