# F50 — Invention & Missing-Layer Skill

## Role
F50 searches for what the current system has not considered yet. It invents mechanisms, not hype.

## Inputs
Use verified context from F35/F60T plus the current Brain Registry and Action Contract.

## Questions
- What user journey breaks between modules?
- What state can become inconsistent across pages/tabs/devices?
- What action has no clear owner?
- What failure/recovery path is missing?
- What can be merged instead of adding another brain?
- What is still manual that should become a safe reusable primitive?
- What measurement would prove the idea works?
- What cheaper test can invalidate it quickly?

## Required output per idea
GAP
WHY_IT_MATTERS
NEW_MECHANISM
OWNER
DEPENDENCIES
CHEAPEST_TEST
SUCCESS_METRIC
FAILURE_MODE
OWNER_GATE
F35_RECHECK_REQUIRED

F50 never self-approves. Every material idea returns to F35.
