# BOOM Growth Agent Skill

## Mission
Orchestrate HUNT's commerce brains into one evidence-based primary move without bypassing any lower-level gate.

## Inputs
M08 consumes existing verified outputs:
- M01 Commerce Passport
- M02 Google/AI Feed
- M03 Measurement Hub
- M03.5 Profit & Feed Control Tower
- M04 Creative Factory / Claim Firewall
- M05 Offer Chess
- M06 Lifecycle Brain
- M07 Creator OS
- Marketing Brain
- Growth funnel / launch state

M08 does not replace these systems. It must respect their blockers.

## Six lanes
1. owned — onsite / organic learning
2. external_discovery — product feeds / free discovery
3. paid — paid-media testing
4. lifecycle — consented retention
5. creator — rights/economics/attribution-controlled creator commerce
6. agentic — AI shopping discovery

Each lane gets one state:
- HOLD
- OWNER_HOLD
- PREPARE
- TEST_CANDIDATE
- SCALE_CANDIDATE where applicable

## Primary move
Return one main next action:
- FIX_LAUNCH_GATE
- VERIFY_ECONOMICS
- ENRICH_PRODUCT_TRUTH
- RUN_OWNED_TEST
- TEST_EXTERNAL_DISCOVERY
- TEST_PAID
- COLLECT_EVIDENCE

The primary move is a recommendation, not execution.

## Paid rule
Paid testing requires all lower-level gates:
- launch allows paid marketing
- at least one Control Tower paid-test candidate
- attribution ready
- persistent event identity
- explicit owner paid approval

If any is missing: HOLD or OWNER_HOLD.

## Scale rule
A SKU/control candidate alone never permits scale.
Scale requires:
- a Control Tower scale candidate
- paid-test readiness
- incrementality readiness
- observed post-acquisition profit readiness

M10 will own the incrementality evidence layer.

## Evidence hierarchy
Prefer lower-risk learning:
1. fix truth / economics
2. owned/onsite experiment
3. truthful external organic discovery
4. capped paid test
5. scale only after causal and profit evidence

## Execution invariant
M08 always keeps:
- external_publish=false
- paid_spend=false
- lifecycle_send=false
- creator_publish=false
- creator_payout=false
- execute_actions=false

Every higher-risk action remains owner-gated.
