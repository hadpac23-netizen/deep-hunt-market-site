# HUNT Cinematic UI

Preserve the approved identity:
- Original Cinematic composition.
- Sapphire / Gold.
- Light / Dark.
- premium world/depth feeling.
- Living Campaign / Advertising & Promotions floor.
- main categories at top.
- selected category reveals departments directly underneath.
- selected department products appear below the campaign floor.
- primary product browsing is vertical.

Design rules:
- Prefer restrained motion and meaningful depth over decorative clutter.
- Use micro-interactions to confirm state, not to obscure navigation.
- Keep promotion/editorial content visually separate from product inventory.
- Do not convert HUNT into a generic ecommerce template or dashboard.
- Mobile must reflow without page-wide horizontal scrolling.
- Respect prefers-reduced-motion.
- Build substantial visual experiments in a new version file.

Before coding, identify:
- approved baseline
- exact visual delta
- protected layout/interaction behavior
- rollback path

After coding, use hunt-visual-qa.
