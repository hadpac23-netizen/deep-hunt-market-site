HUNT SELLER API · V1

Connect your catalog
to HUNT.

Approved merchants can create a Seller API key and submit products individually or in batches. Every new or changed product returns to HUNT review before publication.

Authentication

Send the Seller API key in the Authorization header. Keys are shown once when created in the seller dashboard.

Authorization: Bearer hunt_sk_...

Do not put Seller API keys in browser code, public repositories or product feeds.

Important: product_url must use the approved store domain. Images and videos must use HTTPS. Product videos are reviewed separately and appear only after HUNT verifies that the video belongs to the exact product.

Publishing lifecycle

  1. Merchant submits product.
  2. HUNT validates the payload and safety rules.
  3. Status becomes pending_review.
  4. HUNT admin approves or rejects the product.
  5. Approved products become eligible for HUNT shelves.

An API response of 201 means the submission was accepted for review; it does not mean the product is already public.

External-store attribution

Approved external-store products use HUNT's redirect service to create a first-party click_id. Affiliate networks can be configured by HUNT admin to pass that value into their supported SubID / ClickRef field.

HUNT does not use arbitrary destination URLs from the shopper. The destination comes from the approved merchant product or store record.
